## Why

DRF 3.14 is old, and later DRF versions drop Django 4.2. 3.17 is the last line that supports Django 4.2, so it is the step before Django 5.2 ([ADR-050](../adr/ADR-050-platform-versions.md)).

## Before you start

- Issues 0025 (characterization harness) and 0039 (lock file) must be merged.

## What to do

1. Write characterization tests for 5 busy routes covering success, validation error, token failure and not found:
   - the user profile;
   - the leaderboard;
   - the task list;
   - interest-group details;
   - signup.

   Never pin a success that should be a refusal: if a route answers a caller it should refuse, stop and report it privately as `SECURITY.md` describes.
2. Upgrade `djangorestframework` to the latest 3.17.x in `requirements.txt` and the lock file.
3. Fix any deprecation or behaviour change the tests reveal.
4. Run the full suite on both tiers.

## Acceptance criteria

- [ ] The characterization tests pass unchanged before and after the upgrade.
- [ ] Both test tiers pass.
- [ ] Release notes list any behaviour difference found.

## How to test

```sh
scripts/test.sh tests/characterization/ tests/
```

## Out of scope

- Django itself (issue 0042).
