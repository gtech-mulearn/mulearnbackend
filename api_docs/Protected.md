# Protected API Reference

## Organisation
**Base URL:** `/api/v1/protected/organisation/`

### Get Institutions
**Endpoint:** `institutes/<str:organisation_type>/<str:district_name>/`
**Method:** `GET`
**Brief:** Get institutions by type and district.

### Retrieve Institutes
**Endpoint:** `get-institutes/<str:district_name>/`
**Method:** `GET`
**Brief:** Retrieve institutes in a district key-value pair.
