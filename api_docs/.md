# API

Base path: `/api/`



## Endpoint: `auth/`

- Brief: List or collection endpoint. Returns paginated results.

- Request body example (JSON):
```json
{
  "name": "example_name"
}
```

- Response example (success):
```json
{
  "hasError": false,
  "statusCode": 200,
  "message": {
    "general": []
  },
  "response": {
    "data": [
      {
        "id": "9f4b6c2e-...",
        "name": "example_name"
      }
    ],
    "pagination": {
      "count": 1,
      "totalPages": 1,
      "isNext": false,
      "isPrev": false,
      "nextPage": null
    }
  }
}
```
